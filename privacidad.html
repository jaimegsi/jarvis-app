Política de privacidad de Jarvis

Última actualización: 16 de noviembre de 2026

1. Quién la usa

Jarvis es una aplicación de uso estrictamente personal. Su único usuario es su autor, que es también el titular de las cuentas de Google a las que accede. No hay más usuarios ni se ofrece a terceros.

2. Qué datos de Google se usan

Con la autorización del usuario mediante OAuth de Google, y siempre en solo lectura, Jarvis puede consultar:

  • Gmail: buscar y leer mensajes (permiso gmail.readonly).
  • Google Calendar: consultar calendarios y eventos (calendar.readonly).
  • Más adelante, Google Tasks, Contactos y Drive, también en solo lectura.

Jarvis no envía correos, no crea, modifica ni borra eventos, tareas, contactos ni archivos.

3. Para qué se usan

Solo para responder a las peticiones del propio usuario (por ejemplo, «¿qué tengo mañana?») y para prepararle resúmenes y recordatorios. Los datos no se usan con fines publicitarios, no se venden y no se ceden a terceros.

4. Dónde se tratan y cuánto tiempo se guardan

  • La aplicación se ejecuta en un servidor privado del usuario, accesible solo a través de su red privada.
  • Los tokens de acceso se guardan en ese servidor en un archivo que solo puede leer el usuario de la aplicación y nunca se publican ni se incluyen en copias de seguridad.
  • El contenido de correos y eventos se consulta en el momento y no se guarda en bases de datos ni en registros de forma permanente.
  • Para generar las respuestas, el texto necesario se envía al proveedor del modelo de lenguaje (API de Anthropic) únicamente para procesar esa petición.

5. Cumplimiento con Google

El uso y la transferencia de la información recibida de las API de Google cumplen la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

6. Cómo retirar el acceso

El acceso puede revocarse en cualquier momento desde myaccount.google.com/permissions. Al revocarlo, Jarvis deja de poder consultar los datos y se eliminan los tokens guardados.
